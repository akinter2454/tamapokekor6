💾 세이브 유지

이 브라우저는 설치를 지원하지 않습니다. HTTPS에서 열어 주세요.

🧹 완전 초기화

이 브라우저는 설치를 지원하지 않습니다. HTTPS에서 열어 주세요.

v3.37 설치 방식: 세이브 유지는 앱 바이너리만 기록하고 ESP Web Tools의 데이터 삭제 선택을 사용자에게 표시합니다. 유지하려면 설치창에서 데이터 삭제를 선택하지 마세요. 완전 초기화는 전체 플래시를 지운 뒤 4개 펌웨어 영역을 다시 설치합니다.

필요한 4개 파일명 / 주소
  • bootloader.bin → 0x0000
  • partitions.bin → 0x8000
  • boot_app0.bin → 0xE000
  • app.bin → 0x10000

2microSD 스프라이트 넣기

펌웨어 설치 후 보드를 정상 부팅하고 microSD 카드를 꽂으세요. 기기 연결을 누른 뒤 원하는 지역을 선택하면 스프라이트를 USB Serial로 전송합니다.

지역 하나가 약 20–42MB라 몇 분 이상 걸릴 수 있습니다. 전송 중에는 탭과 USB 연결을 유지하세요. v3.62.6부터 기본 지역 팩도 고정된 검수 버전에서만 받고, 전송 전에 지역 범위/파일 형식까지 검사합니다. 연결 직후 펌웨어/SD 상태를 먼저 확인한 뒤 전송 버튼이 활성화됩니다.

연결 안 됨

메가진화 36종만 추가는 Mega36의 일반/색이 다른 스프라이트만 전송합니다. 현재 추가 스프라이트 전체는 810번 이후 신규 세대·공식 폼·Mega36을 현재 카탈로그 ID대로 모두 다시 기록합니다.

💾 권장: PC에 전체 스프라이트 ZIP을 한 번 저장

현재 빌드의 관동~팔데아·공식폼·Mega36을 모두 합친 mons/ 폴더를 ZIP 하나로 받습니다. 기기의 전원을 끄고 microSD를 PC에 연결한 뒤, 기존 /mons를 백업/삭제하고 ZIP의 mons 폴더를 SD 루트에 복사하면 됩니다. Web Serial로 수천 파일을 다시 전송할 필요가 없습니다. v3.62.8부터 대용량 ZIP은 sprites-current GitHub Release 하나에만 저장되고, 새 빌드가 같은 파일을 교체합니다. Actions Artifact에는 전체 ZIP을 올리지 않습니다.

빌드 정보 확인 전
USB로 직접 전체 동기화

카드리더기를 사용할 수 없을 때만 권장합니다. 관동→성도→호연→신오→하나→칼로스→알로라 기본팩을 검수된 고정 commit에서 받아 지역 ID/TPK 형식을 확인한 뒤 차례로 전송하고, 가라르·히스이·팔데아·공식폼·Mega36 전체를 현재 ID로 덮어씁니다. 먼저 과거 버전이 잘못 species로 만든 AltColor / Alternate / Cutscene / Beta 스프라이트 파일을 자동 정리합니다. 플레이 세이브는 삭제하지 않습니다.

현재 빌드가 사용하는 내부 ID → 포켓몬 이름 → National Dex → PMDCollab 원본 경로를 직접 확인할 수 있습니다. 810번 이후 항목은 실제 TPK3 생성에 사용한 원본에서 뽑은 미리보기 PNG를 표시합니다.

자동 전송이 막히면 을 사용할 수 있습니다.
