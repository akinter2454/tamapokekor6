TamaPoke KO v3.63.6 - 기술/전용기 확장

현재 펌웨어 표시 버전: 3.64.0

- 기술 수: 90 -> 124 (34개 추가)
- 추가 전용기/대표 기술은 해당 포켓몬의 레벨업 목록에 연결됨
- 신규 전투 효과:
  * 확정 급소 / 높은 급소율
  * 공격 후 자신 또는 상대 능력 변화
  * 상대의 상승한 능력 단계 강탈
  * 흡수 회복 결과 기록 및 화면 안내
- 모든 추가 기술에 한국어 이름 적용
- 전투 설명에 능력 상승/하락, 능력 강탈, HP 회복 안내 추가
- 좋은 이별은 부화 후 즉시 선택 가능하며, 진화 레벨 패널티가 없음
- 개체값 상승 사탕 4종은 육성 아이템 1/3 페이지에 표시됨
- 개체값 상승 사탕 사용 후 가방이 유지되어 연속 사용 가능(닫기로 종료)
- 공격/방어/스피드 훈련 상승량 상향(세션 최대 18 -> 24)
- 체력 훈련 추가: 확대·축소되는 심장 고리를 초록 구간에서 터치하는 12라운드 게임
- 체력 훈련치는 실제 최대 HP와 육성 슬롯/파티 전투에 반영됨
- 공격/방어/스피드 훈련에서는 체력 개체값 사탕이 나오지 않음
- 체력 훈련 완료 시 체력 개체값 사탕 5개(30% 확률로 총 9개),
  샤이니 사탕은 다른 훈련과 동일하게 30% 확률
- 진화 버튼과 진화 확인창은 포켓몬 카드의 능력치/개체값 페이지에서만 표시됨
- 홈 화면을 진화창이 가리지 않으므로 중간 진화 포켓몬을 그대로 보고 육성 가능
- 체육관 출전 선택 범위를 현재 육성 포켓몬·파티 6칸·박스 18칸으로 확장
- 3마리 타입 보스도 같은 전체 목록에서 정확히 3마리를 직접 선택해 도전
- 선택 화면 각 카드에 현재/파티/박스 출처를 표시하며 저장 위치는 변경하지 않음
- 멤버 선택 화면의 출력·터치 우선순위를 최상위로 올려 박스/보스/체육관 화면에 가려지는 문제 수정
- 출전 선택 화면 상단에 현재·파티/박스 탭을 추가해 스와이프 없이 저장 위치를 직접 전환
- 탭을 바꿔도 앞서 선택한 포켓몬은 유지되며 전체 선택 수에 함께 반영

간소화 규칙:
- 지오컨트롤은 TamaPoke의 빠른 전투 흐름에 맞춰 충전 없이 즉시 능력이 상승함.
- 사이코브레이크와 신비의칼의 방어 참조 차이, 특성 무시, 방어 기술 관통 등은
  현재 전투 엔진에 해당 시스템이 없어 기본 피해 기술로 처리함.
- 섀도다이브는 기존 충전 기술 방식으로 2턴에 걸쳐 발동함.
- 썬더프리즌의 교체 봉쇄/지속 피해는 마비 확률로, 소금절이의 지속 피해는
  독 상태로 간소화함. 찍찍베기는 전투 엔진의 2~5회 연속 공격을 사용함.
