TamaPoke v3.85.0 디지몬 SD 팩 만들기

일괄 변환
- ver1~ver5 폴더 안에 캐릭터별 ZIP이 들어 있는 바깥 ZIP을 그대로 선택할 수 있습니다.
- 내부 캐릭터명과 도감 이름은 영문판/일본판 명칭 차이까지 자동 대응합니다.
- 같은 융합체가 두 버전 폴더에 있거나 동일 파타몬 ZIP이 중복되어도 한 번만 생성합니다.
- 완료 로그와 manifest.txt에서 생성·중복·미인식·누락 수를 확인할 수 있습니다.

권장 방법: Digimon-SD-Pack-Maker.html을 Chrome 또는 Edge에서 열고,
Digimon Sprites.zip을 선택한 다음 SD 팩 만들기를 누릅니다.

지원 PNG 형식
- 48x48: 정지 이미지 1장을 3프레임으로 복제
- 144x48: 48x48 프레임 3장을 가로로 배치
- 48x144: 48x48 프레임 3장을 세로로 배치
- 48x64: 구형 DMC 시트의 첫 줄 16x16 3장을 48x48로 최근접 확대

새 DGI1 파일은 3프레임 x 48x48 RGB565이며 파일당 13,834바이트입니다.
기존 3프레임 x 16x16 DGI1 파일도 펌웨어에서 계속 읽을 수 있습니다.

15프레임 애니메이션 팩
- ZIP 최상위에 0.png부터 14.png까지 48x48 PNG를 넣습니다.
- HTML 생성기에서 적용할 디지몬을 선택하고 SD 팩 만들기를 누릅니다.
- DGI3 파일은 15프레임 x 48x48 RGB565이며 파일당 69,130바이트입니다.
- DGI3는 투명색 0x0001과 검정색 0x0000을 구분합니다. 구형 DGI1/DGI2도 계속 읽습니다.
- 펌웨어는 대기, 걷기, 방향 전환, 반응, 휴식, 훈련 동작으로 프레임을 배치합니다.
- 걷다가 돌아오는 동작은 같은 프레임을 좌우 반전하므로 별도 반대 방향 PNG가 필요하지 않습니다.

1. 이 폴더의 build_user_digimon_pack.py와 사용자가 보유한 Digimon Sprites.zip을 프로젝트 루트에 둡니다.
2. Pillow를 설치한 Python 환경에서 다음 명령을 실행합니다.
   python tools/build_user_digimon_pack.py "Digimon Sprites.zip"
3. 생성된 sdcard/digimon 폴더를 SD 카드 최상위에 복사합니다.
4. SD 카드에는 /digimon/d000.dgi 형태로 표시되어야 합니다.

이 배포 파일에는 원본 PNG 도트가 포함되어 있지 않습니다.

SD 카드 장착 방법
1. 기기 전원을 완전히 끕니다.
2. microSD를 분리하여 컴퓨터에 연결합니다.
3. 생성된 digimon-sdcard.zip을 풀고, 안의 digimon 폴더를 카드 최상위에 복사합니다.
4. 기존 mons 폴더와 그 내용은 삭제하거나 덮어쓰지 않습니다.
5. 안전하게 하드웨어 제거 후 카드를 기기에 다시 넣고 전원을 켭니다.

v3.85.0은 SD 마운트 실패 시 자동 포맷하지 않습니다. /mons는 포켓몬,
/digimon은 디지몬 도트 전용이며 포켓몬 저장값은 NVS의 tamapoke,
디지몬 저장값은 별도 digipet 영역을 사용합니다.
